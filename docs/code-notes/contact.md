# Contatti (`#contatti`)

## Scopo

Invitare chiese ed eventi a contattare Soundchest via email, social o **chat** (widget in basso a destra).

## Markup

- Sezione: `#contatti`
- Lead copy + `.contact-links`
- Link attuali:
  - `mailto:info@soundchest.it`
  - Instagram / YouTube → `href="#"` (da sostituire con URL reali)

## Chat

Per messaggi interattivi usare [chat.md](chat.md); questa sezione rimanda esplicitamente al FAB chat.

## Personalizzazione

```html
<a href="https://instagram.com/..." class="contact-link">Instagram</a>
```

Verificare email di dominio reale prima del go-live.
