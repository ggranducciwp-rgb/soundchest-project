## Regole per gli sviluppatori (e assistente AI)

1. Aggiornare il `.md` corrispondente **prima** di commit/PR.
2. Nei commit citare il file doc, es. `feat: chat — aggiorna docs/code-notes/chat.md`.
3. Se la richiesta non è documentata, aggiungere sezione **Domanda ricevuta** nel `.md` pertinente.
4. Segnalare **INCONGRUENZA** se codice e doc divergono.
